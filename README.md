Starshard Warden is a neon arena-defense game for the desktop browser. You pilot the last Warden around the final Star Core: hold ten waves of the Hollow swarm, harvest starshards from the fallen to draft upgrades as you level, and when the Hollow Star itself arrives on wave ten, put it down. The Warden falling — or the Core going dark — ends the run. Everything runs from static files with no network request, and all art and sound are generated by the game's own code: canvas vector art and a WebAudio synth, no assets.

## Run it

```sh
node serve.ts
# then open http://localhost:8080/game/ in a desktop browser
```

Any static file server pointed at the `game/` folder works just as well. Move with WASD or the arrow keys, aim with the mouse, hold click (or J) to fire, dash with Space or Shift, pause with P, mute with M.

To hand the entry in the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
